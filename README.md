# PHP-Tris-Game 🎮

**Tris (Tic Tac Toe) PHP + CSS responsive. 1 giocatore vs computer (solo server-side).**

[![PHP](https://img.shields.io/badge/PHP-8.2+-pink)](https://php.net)
[![CSS3](https://img.shields.io/badge/CSS3-1572B6)](https://css3.com)

<br>

## 📖 Descrizione
**Tris puro PHP** – griglia 3x3 con logica server-side completa.
- **Modalità:** 1 Giocatore vs Computer
- **PHP:** Turni, mosse, controllo vincita
- **CSS:** Griglia responsive + design moderno
- **No JavaScript** – tutto server-side
  
  <br>

**Obiettivo CV:** PHP game logic + CSS responsive puro.

<br>

## 🛠 Tech Stack
- **Backend:** PHP 8+ (array 3x3, algoritmo vincita)
- **Frontend:** HTML5 + CSS3 Grid
- **Responsive:** Mobile/Desktop
- 
  <br>

## 🚀 Setup XAMPP
```bash
1. XAMPP > Apache START
2. htdocs/tris/
3. http://localhost/tris/
```
